# Jingbao Store

镜宝应用商店的后台数据仓库，为镜宝提供应用元数据和资源文件。

## 目录结构

```
jingbao-store/
├── apps/               # 应用列表目录
│   ├── games/          # 游戏分类
│   └── applications/   # 应用分类
├── README.md           # 本文件
└── LICENSE             # 许可证
```

## 使用说明

详细的应用管理说明请参见 [apps/README.md](./apps/README.md)。

## 贡献指南

欢迎提交新的应用或更新现有应用的信息。请确保：

1. 所有 JSON 文件格式正确
2. 图标和截图链接有效
3. 应用信息准确完整
4. 遵循目录结构规范
